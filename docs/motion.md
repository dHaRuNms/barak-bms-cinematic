# Engineering animation

The first release used a generated still and a finite entrance. A subsequent runtime WebGL version added continuous geometry, but the user still reported seeing no animation. The current homepage uses a locally rendered silent film through native video so visible motion does not depend on visitor-side WebGL. The procedural scene remains the film's source.

- **Focal moment:** authored housing, cells, circuit board, and cooling cover separation, changing orientation, and moving studio light. The film has no runtime pointer response or scroll-controlled battery geometry.
- **Media:** `public/video/battery-assembly-v2.mp4`. `scripts/render-hero-film.mjs` samples `src/scene/batteryScene.ts` through `renderFilmFrame` at 288 exact timestamps and encodes a 12-second, 1080×960, 24fps H.264 MP4 with fast-start metadata and no audio. These are export settings, not certified physical-device playback results.
- **Continuity:** the film loops in the hero. Supporting SVG signal paths progress with scroll and pulse only in view while motion is enabled. The introduction's muted phrase brightens with scroll. Text remains visible without animation; solution imagery retains short transitions.
- **Controls:** visible “Play animation” / “Pause animation” text on desktop and mobile controls the film and supporting motion. Reduced motion starts paused, with the poster, completed SVG diagram, and a visible Play action allowing explicit film opt-in; supporting CSS animation stays reduced. Autoplay denial exposes Play. Media failure restores the poster and offers “Retry animation,” remounting the video.
- **Loading and lifecycle:** muted, looping, inline video uses `preload="none"`; its source is assigned only for visible, unpaused playback in an active document. Initial hash navigation is instant, so a direct Contact link defers media. Offscreen, hidden-tab, and user-paused states pause playback. Cleanup removes the source and observers/listeners. The production homepage does not initialize WebGL or use the prior scene's DPR, frame ceiling, or adaptive-resolution settings.
- **Visual authority:** retain the warm dark world, copper accents, copy, and concept-image caveat. The film is an illustrative model, not evidence of released hardware. Desktop places it to the right of the statement; mobile places it above the statement. Preserve explicit playback controls alongside this composition.

Re-export with `node scripts/render-hero-film.mjs` from the project root. The script requires local Chrome and ffmpeg, uses port 4174, writes intermediate PNGs under `tmp/hero-frames`, and writes the MP4 under `public/video`. Build the site after export to include the updated asset.
